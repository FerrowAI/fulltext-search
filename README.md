# Fulltext Search

Lightning-fast full-text search. Index data for Ferrow retrieval agents.

```javascript
const search = new FulltextSearch();
search.index(documents);
const results = search.query('machine learning');
```

## Features
- ✓ Elasticsearch integration
- ✓ Relevance ranking
- ✓ Faceted search
- ✓ Ferrow RAG pipeline
